# One Sol to Rescue · Один сол до помощи

Браузерный тренажёр для NASA Space Apps. Марк поддерживает работу марсианской базы 30 солов до прибытия помощи. Этот репозиторий даёт команде стартовую сборку и контракты для параллельной работы. В ней уже можно открыть экран базы, переключить EN/RU, выделить энергию очистителю и закончить сол.

## Запуск для разработчика

Установите Git и Node.js 22 с npm. После получения доступа выполните:

```bash
git clone git@github.com:Xasoek/qanatHub-game.git
cd qanatHub-game
npm ci
npm run build
npm test
```

Откройте корневой `index.html` двойным щелчком. Игроку достаточно этого файла и браузера. Для сборки после `npm ci` интернет не нужен. Для ручной проверки отключите сеть, откройте файл, начните день, дважды включите очиститель, завершите сол и подведите итоги. Счётчик перейдёт на сол 2, еда уменьшится, кислород сохранится. Переключите язык и начните заново.

`npm run build:check` проверяет, что опубликованный в репозитории HTML совпадает с исходниками. `npm run sim -- 1000` запускает 1 000 партий с простым выделением энергии на воздух. Пока урожая и событий нет, этот результат проверяет, что партии завершаются. Целевой баланс и стратегии реализует роль 1. Архив NASA в стартовой сборке пуст, интерфейс показывает «Ожидаются данные NASA».

## Кто за что отвечает

| Роль | Файлы | Ветка для первой задачи |
| --- | --- | --- |
| 1 · Логика и баланс | `src/config.js`, `src/engine.js`, `tools/sim.js` | `role-1/engine` |
| 2 · Интерфейс и графика | `src/ui.js`, `src/art.js`, `src/style.css` | `role-2/ui` |
| 3 · Данные NASA | `src/data.js` | `role-3/nasa-data` |
| 4 · Сюжет и локализация | `src/text.js` | `role-4/story` |
| 5 · Интеграция | `src/main.js`, `tools/build.js`, `tools/smoke.js`, `index.html`, документация и CI | `role-5/integration` |

## GitHub Pages

Когда команда готова опубликовать сборку, владелец или администратор выбирает **Settings → Pages → Deploy from a branch → main → /(root) → Save**. После публикации GitHub покажет адрес в этом же разделе. Для приватного репозитория возможность публикации зависит от тарифа. Доступ к опубликованной странице и доступ к репозиторию настраиваются в GitHub. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
