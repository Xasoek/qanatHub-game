Вступление из пяти кадров доступно через меню. Основной вход остался на настройке
миссии. Сохранились 3D-база, корабль, исправленные материалы и расчистка заносов.
На телефоне интерфейс работает в горизонтальной ориентации согласно запросу пользователя.
Карточки систем прокручиваются по горизонтали, чтобы сохранить кнопки 44×44.

Презентация использует классические пресеты движка команды. Обычная новая миссия
использует ранее согласованное расширение симулятора. Оно затрагивает config.js,
engine.js и simulator.js, поэтому при последующей командной интеграции их надо
переносить вместе с UI и контрактом. Правки текущего main в движке и данных сохранены.
Запись sourceFlare в журнале сохраняет точную NASA-ссылку после загрузки.

## Проверки

- npm test — 29 тестов, smoke сборки, 36 записей NASA.
- npm run build:check — HTML соответствует исходникам.
- npm run test:browser — 7 проверок Chromium, включая горизонтальный телефон.
- node tools/demo-rehearsal.js — реальный интерфейс, виртуальные часы Playwright.
  Полный акт 3 завершился спасением за 294 виртуальные секунды (4:54), включая решения.
  Это ускоренная репетиция, а не замер пяти минут физического времени.
- node tools/hardware-ui-check.js — Chrome с аппаратным 3D на Apple M3,
  распределение энергии, планирование, переход сола, меню, Continue и телефон.
- npm run sim -- 1000 — пакетная симуляция классического движка с архивом NASA.

Сетевые тесты подтверждают подключение UI к модулю данных на управляемых ответах.
Они не гарантируют доступность внешнего NASA API в момент показа.
Ветка содержит исходники, автономную сборку и проверки интеграции.
