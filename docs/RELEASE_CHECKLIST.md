# Чек-лист тестирования и выпуска

Для каждого кандидата запишите SHA коммита, ссылки на PR и Actions, версии браузеров и результаты ручных проверок. Укажите устройство и шаги воспроизведения для каждого сбоя.

## До объединения PR

- [ ] Сверить изменения исходников с [границами ролей](../TEAM_GUIDE.md) и [контрактами](../CONTRACTS.md). Проверить потребителей общего API и обе локализации.
- [ ] Из чистой копии на Node.js 22 выполнить `npm ci`, `npm test`, `npm run build:check`, `npm run build`, `npm run test:browser` и `npm run sim -- 1000`. Убедиться, что задание **smoke** прошло на PR.
- [ ] Проверить воспроизводимость на том же коммите. Две последовательные сборки должны дать одинаковый SHA-256 и совпасть с файлом в Git.

  ```bash
  npm run build:check
  npm run build
  node -e "const {createHash}=require('node:crypto'); console.log(createHash('sha256').update(require('node:fs').readFileSync('index.html')).digest('hex'))"
  npm run build
  node -e "const {createHash}=require('node:crypto'); console.log(createHash('sha256').update(require('node:fs').readFileSync('index.html')).digest('hex'))"
  git diff --exit-code HEAD -- index.html
  ```

- [ ] Проверить состав изменений и готовый HTML. Ключи, локальные конфиги и временные файлы должны оставаться вне коммита и артефакта.
- [ ] Запустить файл по сценарию ниже и записать, какие пункты ещё требуют работы владельцев модулей. Получить ревью перед объединением.

## Ручная проверка игры

| Сценарий | Ожидаемый результат |
| --- | --- |
| Скопировать только `index.html` в отдельную папку, отключить сеть и открыть файл | Вступление, SVG базы и архив NASA загружаются. В консоли нет ошибок. |
| Выбрать Гейл, начать день, выделить энергию очистителю, завершить сол и применить итоги | Открывается сол 2. Счётчики ресурсов обновляются по итогам выбранных действий и событий первого сола. |
| Переключить EN/RU во вступлении, партии и образовательных экранах | Подписи и реплики меняются, текущий сол сохраняется. Факты, источники и материалы для учителей доступны. |
| Дойти до бури. Один раз выбрать действие, второй раз дождаться таймера | Выбор меняет состояние. По истечении 10 секунд на Engineer или 15 секунд на Cadet действует вариант по умолчанию. |
| Дойти до вспышки и выбрать укрытие или продолжение работы | Событие показывает класс. В разделе фактов можно увидеть дату и класс использованной записи DONKI. |
| Пройти до сола 30 и отдельно исчерпать запас кислорода или еды | Появляется экран спасения или аварийного сна с итогами решений. Повторный старт открывает настройку новой миссии. |
| Проверить Chrome, Firefox, Safari и сенсорное устройство, включая ширину 360 px | Кнопки доступны, сцена и подписи читаются, горизонтальная прокрутка отсутствует. Chromium в CI проверяет два размера окна. |
| Сохранить миссию, перезагрузить игру, затем запустить акт презентации | Продолжение восстанавливает состояние. После выхода из презентации исходное сохранение доступно. |
| В настройках NASA DONKI запросить свежие данные без сети | Игра продолжает работу на архиве и показывает его как источник данных. |
| Открыть доску заданий и запланировать ремонт | Видны стоимость, условия и статус. После завершения сола результат отражается в состоянии системы. |

## После одобренного объединения

- [ ] В **Settings → Pages** выбран **GitHub Actions**. На запуске для нужного SHA оба задания, **smoke** и **Deploy to GitHub Pages**, завершились успешно.
- [ ] Открыть URL из задания публикации в приватном окне, проверить доступ без входа и сыграть первый сол. Скачать опубликованный `index.html` и сверить SHA-256 с проверенной сборкой.
- [ ] Сохранить этот же HTML для офлайн-демо и передать команде ссылку на проверенную версию и [сценарий презентации](DEMO.md).
- [ ] Если сайт недоступен, проверить источник Pages, журналы заданий и статус адреса в **Settings → Pages**. Ошибку сборки исправить PR. Для восстановления предыдущей версии согласовать revert PR и дождаться его публикации.
- [ ] Указать рабочую ссылку, выбранный challenge, источники и ссылку на демо в заявке команды. Подтвердить отправку в NASA Space Apps отдельно от публикации игры.
