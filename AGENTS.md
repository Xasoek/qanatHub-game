# One Sol to Rescue

В начале задачи прочитай назначение файлов в [README](README.md) и [контракты](CONTRACTS.md). Уточни по задаче, за какую роль работаешь. Изменяй её файлы. Изменения общего API включай в PR вместе с документацией и проверкой затронутых модулей.

- Весь код браузера — ES-модули. Движок и конфиг должны импортироваться из Node.js для симуляции.
- Игровые числа храни в `CONFIG`. Видимые игровые строки добавляй с одинаковыми ключами в `TEXT.en` и `TEXT.ru`.
- UI использует методы движка для изменения `STATE`. Графика возвращает встроенный SVG.
- Сборка должна открываться из `file://` офлайн. Встраивай CSS, JS и графику. Ключи доступа держи за пределами репозитория и собранного HTML.
- Запусти `npm test`, `npm run build` и `npm run build:check`. Генерируй `index.html` из исходников.
- Для Claude Code передай в начале задачи `@AGENTS.md` и свой номер роли. Для Codex укажи номер роли в задаче.

Порядок ревью и обновления веток описан в [CONTRIBUTING](CONTRIBUTING.md).
